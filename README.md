# 🎮 Delta Force - Auto Redeem Gift Code Tool

Tool tự động nhập hàng loạt Gift Code dành cho game **Delta Force**, chạy trực tiếp trên trình duyệt web (Console) với giao diện **Modern Glassmorphic** chuyên nghiệp và dễ sử dụng.

---

## 🌟 Tính năng nổi bật

* ✨ **Giao diện Glassmorphic hiện đại**
  Hiển thị bảng điều khiển nổi (HUD) sang trọng, cung cấp:

  * Thanh tiến trình (Progress Bar)
  * Thời gian thực hiện
  * Mã code đang xử lý

* ⚡ **Tự động đóng Popup (Auto-Close Popups)**
  Sử dụng `MutationObserver` để tự động đóng các thông báo/popup kết quả ngay khi xuất hiện.

* 🧠 **Xử lý sự kiện chuẩn (Native Event Simulation)**
  Tự động gửi các sự kiện `input` và `change`, mô phỏng hành vi người dùng thật → tương thích tốt với các framework như **React / Vue**.

* 🧹 **Lọc trùng & tối ưu hóa**

  * Loại bỏ code trùng lặp
  * Xoá khoảng trắng dư
    → Giúp tăng hiệu suất và tránh lỗi

* 🎁 **Kho Gift Code lớn**
  Tích hợp sẵn danh sách gift code mới nhất, sẵn sàng sử dụng ngay.

## 🚀 Hướng dẫn sử dụng

### 🔹 Cách 1: Chạy trực tiếp từ Developer Console (Khuyên dùng)

1. Mở trang nhập code chính thức của **Delta Force** trên trình duyệt (Chrome, Edge, Brave,...).
2. Đăng nhập tài khoản game của bạn.
3. Nhấn **`F12`** (hoặc chuột phải → chọn **Inspect / Kiểm tra**)
4. Chuyển sang tab **Console**
5. Sao chép toàn bộ nội dung trong file `nhapcodedeltaforce.js`
6. Dán (Paste) vào Console
7. Nhấn **`Enter`** để chạy tool
